# Student and Hotel Management Systems (Java)

## Overview
A collection of modular console applications developed in Java for the Principles of Programming module (SEN4000) under the Cardiff Metropolitan University curriculum. Grade: 80% (First Class).

## Features

### 1. Student Management System (`Studentsmanagementsystem.java`)
- Custom `Student` class for data encapsulation.
- In-memory dynamic storage using Java `ArrayList`.
- Core CRUD operations: add, view, search, and remove records by ID.

### 2. Hotel Management System (`HotelAurora.java`)
- Guest registration and booking calculation by room tier.
- Interactive menu loop for restaurant services.
- Itemized billing tracking laundry and recreational services.
- Comprehensive invoice summary generation.

## Technical Details
- **Language:** Java
- **Core APIs:** `java.util.Scanner`, `java.util.ArrayList`
- **Architecture:** Procedural logic, CLI loops, and basic OOP principles
